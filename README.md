# Encontrando com Deus — Primários 1A

Aplicativo gamificado da Escola Bíblica Dominical para crianças de 7 e 8 anos. 1º módulo: 13 lições, 130 desafios, 2.015 pontos.

**Abrir o app:** https://zaik1966.github.io/ebd-primarios-1a/

A criança pontua a cada resposta certa, recebe uma explicação simples quando acerta e uma dica com convite para tentar de novo quando erra. Os desafios crescem em dificuldade dentro de cada lição. A pontuação e os carimbos do passaporte ficam salvos no próprio aparelho.

Textos bíblicos: Nova Almeida Atualizada, Sociedade Bíblica do Brasil. Ilustrações originais em vetor.
